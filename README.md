# sentiment-analysis-system
基于机器学习与深度学习的情感分析系统
数据收集：使用scrapy爬虫爬取网易新闻的新闻文本数据，提供数据收集，包括训练数据收集和分析数据收集
数据预处理：fenci.py和pre_process.py提供数据标注和预处理，对训练数据进行基本的数据处理
情感分析：训练了SVM和LSTM两个情感分析模型，可分析积极、中性、消极三种情感类型，模型准确率均达到0.81左右。如果需要更高请改进自制的数据集质量，或者使用其它更庞大的数据集
Web：部署在本地的Django Web系统，完成基本可视化，其中分析图包含地图热力图、词云图、词关联图和情感分布饼图
